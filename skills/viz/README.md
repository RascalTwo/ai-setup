# /viz — live ad-hoc visualizations for AI coding agents

Render arbitrary HTML/CSS/JS — charts, graphs, 3D scenes, state machines, dashboards,
animated explainers, custom UIs — and serve it at a live, hot-reloading URL. It's the skill
you point your assistant at when you want to *see* something, not read a wall of text about it.

```bash
npx skills add RascalTwo/ai-setup -s viz
```

## → **[Everything else is in the self-portrait.](https://rascaltwo.github.io/ai-setup/viz-self-portrait/)**

That page is `/viz` rendering itself: an interactive guide covering the four ways to install
it and what each one gets you, what it can do, and how it works underneath — plus a live
dashboard of every viz on the author's machine. It is the documentation, not a demo of it.

There is deliberately no second copy of that here. A README that restated it would drift from
it, and this one already had: it promised "Requirements: Bun" long after that stopped being
the whole truth.
