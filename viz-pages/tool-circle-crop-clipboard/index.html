Round avatars arrive on square backgrounds

Profile photos copied out of chat apps, directories and slide decks come as a circle drawn on a solid square. Pasted onto anything that isn't the same colour, the square shows. Fixing it by hand means an image editor, a selection tool and an export.

circle-crop-clipboard does that in one command and never touches a file.

Copy, run, paste

  • Copy the image (Cmd+C, or a screenshot to the clipboard).
  • Run python3 ~/.agents/ai-setup/tools/circle-crop-clipboard/circle-crop-clipboard.py. It prints the size before and after.
  • Paste wherever the round photo goes.
  • If the crop is off, raise or lower BG_THRESHOLD (default 28) at the top of the script.

What it won't do

  • It assumes a solid background. The background colour is the average of the four corner pixels; a gradient or a photo behind the circle confuses it.
  • It does not find faces. It crops to whatever differs from the background, so a caption or badge on the square widens the circle.
  • macOS only. The clipboard is read and written through AppKit (pyobjc).
  • The pixel scan is pure Python, so a very large image takes a few seconds.

Where it lives

Integrates with The macOS general pasteboard (NSPasteboard), PNG or TIFF in, PNG out. Nothing in Claude Code or the installer.
Requires python3 with Pillow and pyobjc (pip install Pillow pyobjc). Platform: macOS.
Its state None. circle-crop-clipboard keeps nothing on disk.
Safe to delete? Nothing to delete.

One image, end to end

  1. Read. read_clipboard_image() asks the pasteboard for PNG, then TIFF, and opens it as RGBA. No image: it exits with a message.
  2. Background. detect_circle_bbox() averages the four corner pixels into one colour.
  3. Find the circle. Every pixel whose summed RGB distance from that colour exceeds BG_THRESHOLD goes into a mask; the mask's getbbox() is the circle's box. An empty mask falls back to the whole image.
  4. Cut. circle_crop() crops a square around the box's centre with the larger side as diameter, draws an ellipse at 4× size, shrinks it with LANCZOS for smooth edges and uses it as the alpha channel.
  5. Write. write_clipboard_image() clears the pasteboard and puts the PNG on it.
