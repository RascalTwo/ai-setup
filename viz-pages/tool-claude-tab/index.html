Two calls, nothing else

The whole tool is a two-line /bin/sh script talking to herdr's socket API. There is no supervisor, no config file of its own, no process left behind.

pane=$(herdr tab create --focus | jq -r .result.root_pane.pane_id)
exec herdr pane run "$pane" claude --dangerously-skip-permissions

herdr tab create --focus — with no --label, so herdr auto-numbers the tab exactly as it would an unnamed prefix+c tab. The new tab inherits the focused pane's cwd on its own, because herdr's [terminal] new_cwd defaults to "follow". The response carries the new pane at .result.root_pane.pane_id — which is what jq is there for.

herdr pane run — makes claude the pane's foreground process, so the tab behaves as if you had typed the command yourself.

Why herdr still sees an agent

herdr's own agent detection picks claude up from there. The tab reports agent_status: idle once it is ready for input, so the status dots and notification routing work exactly as they do for a hand-started agent.

No herdr agent start call is needed. That one exists for when you want herdr to validate agent identity before proceeding — which a keybinding does not.

Requires herdr and jq. Afterwards: herdr server reload-config. The TOML merge is guarded on the command path, so re-running the installer is a no-op rather than a duplicate binding.

# herdr-keybind.toml — type = "shell" runs detached in the background.
# The script prints nothing and needs no pane of its own; the tab it
# creates IS the visible result.
[[keys.command]]
key = "prefix+a"
type = "shell"
command = "~/.claude/bin/claude-tab"
description = "new tab running claude here"

Two things that bite

herdr does not expand ~ in a [[keys.command]] command field. The literal tilde above never resolves — so install.ts bakes in the absolute path at install time.

A direct chord works too — key = "ctrl+alt+a" instead of prefix+a. It was not chosen, for two reasons: on macOS, Option is not Alt in Ghostty unless macos-option-as-alt is set; and a bespoke chord is one more undocumented thing to remember. prefix+a shows up in herdr's own help with the description above. The chord is just muscle memory.
